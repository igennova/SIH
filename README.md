# SIH Project - Learning Platform for Deaf and Mute People

## Project Overview
This project aims to create an inclusive learning platform specifically designed for deaf and mute individuals. By providing accessible resources through visual, sign language, and interactive content, it helps bridge the communication gap in education. The platform is designed to be user-friendly, ensuring equal learning opportunities.

## Features
- **Sign Language Tutorials**: Offers video tutorials in sign language for easy comprehension.
- **Interactive Lessons**: Visual-based lessons that enhance engagement and retention.
- **Text-to-Sign Translator**: Converts written content into sign language.
- **Community Forum**: A dedicated space for interaction and support among users.

## Tech Stack
- **Frontend**: React.js, HTML5, CSS3, JavaScript
- **Backend**: Node.js, Express.js
- **Database**: MongoDB
- **Additional Libraries**: 
  - **WebRTC** for real-time communication
  - **Sign Language API** for converting text to sign language
  - **Socket.io** for real-time messaging
